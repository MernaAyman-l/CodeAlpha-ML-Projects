# CodeAlpha — Machine Learning Projects

A collection of three academic machine-learning and deep-learning projects completed as part of practical learning tasks. Each project is kept in its own folder with a notebook and project-specific documentation.

## Projects

| Project | Main techniques | Entry point |
| --- | --- | --- |
| [Credit Scoring Classification](./Credit%20Score%20Model/) | Data preprocessing, credit-history target engineering, Logistic Regression, Decision Tree, Random Forest, classification metrics | [Notebook](./Credit%20Score%20Model/Task1%20Credit%20Score%20Model.ipynb) |
| [Heart Disease Prediction](./Disease%20Prediction%20from%20Medical%20Data/) | Classification, feature scaling, Logistic Regression, Random Forest, SVM, XGBoost, ROC-AUC | [Notebook](./Disease%20Prediction%20from%20Medical%20Data/Disease%20Prediciton.ipynb) |
| [Handwritten Digit Recognition](./Handwritten%20Character%20Recognition/) | Computer vision, CNN, TensorFlow/Keras, MNIST, multiclass evaluation | [Notebook](./Handwritten%20Character%20Recognition/Task%203%20Handwritten%20Character%20Recognition.ipynb) |

## Technologies

- Python
- Pandas and NumPy
- Scikit-learn
- TensorFlow / Keras
- XGBoost
- Matplotlib and Seaborn
- Jupyter Notebook

## Getting Started

Each project has its own README with its dataset details and installation instructions. Open the relevant notebook in Jupyter Notebook, JupyterLab, or VS Code after installing that project's dependencies.

## Notes

- These are educational projects, not deployed applications.
- The credit-scoring notebook's target-generation logic was corrected; its saved evaluation outputs were cleared and must be regenerated before quoting model metrics.
- The heart-disease classifier is not a diagnostic tool and must not be used for medical decisions.
- Review each project's README for dataset, reproducibility, and evaluation limitations.
